# 数据上传与自动化分析平台

一个基于 Flask + Pandas + Plotly + Bootstrap 的本地部署数据上传与自动化分析网页应用。

## 功能特性

### 1. 数据上传
- 支持 CSV、Excel (.xlsx, .xls) 格式文件上传
- 拖拽上传或点击选择文件
- 上传后自动显示数据预览（前10行）

### 2. 自动化分析
- **自动变量类型识别**：智能识别数值型（连续/离散）、分类型、日期时间型、布尔型、文本型
- **缺失值检测**：
  - 计算每个变量的缺失数量和比例
  - 热力图可视化缺失分布
  - 条形图展示缺失比例
- **异常值检测**：
  - Z-score 方法（|Z| > 3）
  - IQR 方法（1.5倍四分位距）
  - 箱线图和分布图可视化

### 3. 交互功能
- **变量类型修改**：通过下拉框手动修改变量类型
- **分组分析**：选择分组变量，查看各组统计信息和可视化

## 技术栈

- **后端**：Flask (Python Web 框架)
- **数据处理**：Pandas, NumPy
- **可视化**：Plotly (交互式图表)
- **前端**：Bootstrap 5 (CSS 框架), Vanilla JavaScript

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行应用

```bash
python app.py
```

### 3. 访问应用

打开浏览器访问：http://127.0.0.1:5000

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 主页 |
| `/upload` | POST | 文件上传 |
| `/update_type` | POST | 更新列类型 |
| `/analyze_missing` | POST | 缺失值分析 |
| `/analyze_outliers` | POST | 异常值分析 |
| `/get_groupby_options` | POST | 获取分组选项 |
| `/group_analysis` | POST | 分组分析 |
| `/clear_session` | POST | 清除会话 |

## 使用说明

1. **上传数据**：在主页拖拽或点击上传 CSV/Excel 文件
2. **查看预览**：上传后自动显示数据前10行预览
3. **变量类型**：在"变量类型"标签页查看和修改自动识别的类型
4. **缺失值分析**：在"缺失值分析"标签页查看缺失统计和可视化
5. **异常值检测**：在"异常值检测"标签页查看异常值统计和箱线图
6. **分组分析**：在"分组分析"标签页选择分组变量进行分析

## 注意事项

- 最大支持上传 16MB 的文件
- 数据存储在内存中，刷新页面后需要重新上传
- 支持的数据类型：数值型、分类型、日期时间型、布尔型、文本型
