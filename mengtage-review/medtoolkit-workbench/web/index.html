统计验收

支持合成数据、公开文献提取数据或已脱敏研究数据。也可上传 CSV 自动填充下方表格。

列联表检验

仅合成频数；行列标签按输入顺序保留。自动选择沿用 MedStat 规则，产物记录实际方法及模拟参数。

数值组间比较

仅合成数据，独立组比较。两组输出 Welch、Mann–Whitney 与 Cohen d；多组输出 ANOVA 与 Kruskal–Wallis。请按研究方案确定主要检验。

基线特征表 TableOne

显式指定连续数值与分类变量，可按分类列分组。百分比分母为组内非缺失样本；检验选择沿用旧版 TableOne。

回归分析

仅合成数据和数值预测变量，含截距。按所选变量剔除缺失行；Logistic结果须编码为0/1，1表示事件。Poisson须为非负整数；Gamma须严格为正，沿用inverse链接，不将其系数解释为OR。

预测评估

仅合成数据。显式指定概率、阈值和数据来源：training、held_out或external；来源为用户声明。

预测评估补充：HL / DCA / NRI / IDI

仅合成概率数据。HL沿用等宽分组；新旧模型每行对应同一受试者和结局时间点。NRI按每个阈值分别二分类，IDI推断仅基于固定预测。单模型时删除old_probability、nri_thresholds和paired_confirmed。

连续数据插补

仅合成连续变量，缺失用null。Bayesian Ridge支持多份插补及列均值合并；linear/ridge只允许单次。不自动识别999等缺失码。
