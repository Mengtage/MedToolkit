## Notes

- This table covers **high-frequency terms** across major medical specialties (~100 entries). The complete MeSH vocabulary contains ~30,000 descriptors.
- For comprehensive MeSH browsing, always use the [NCBI MeSH Database](https://meshb.nlm.nih.gov/).
- MeSH terms are **hierarchical** — explosion (`explode all trees`) includes all narrower terms.
- Some terms have **Entry Terms** (synonyms) that are automatically mapped (e.g., "cancer" maps to "Neoplasms").
- MeSH is updated annually. Verify terms against the latest version.
