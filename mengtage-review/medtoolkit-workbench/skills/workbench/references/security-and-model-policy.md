## 用户信息与数据安全

默认最小化收集，区分账户信息、公开文献、受许可全文、研究数据与可识别病例信息。病例原始数据、身份映射、凭证不得进入模型提示词或普通日志；统计在受控计算环境完成。去标识化不自动等于可外发，稀有病例、小样本分组和自由文本仍需评估重识别风险。Gemini 仅接收经授权且必要的材料；第三方处理、存储地区、保留政策与机构要求在实际接入前核对。

工程接入须具备按项目授权、传输与存储保护、脱敏日志、导出与删除记录、备份恢复、保留期限配置。当前本地脚本不实现这些完整安全能力，不用于真实患者数据上线。先使用公开文献与合成数据验收。原文件只读归档，派生版本可追踪；不得将患者数据送到外部模型排查错误。

## 幻觉与科研严谨性

每条文献结论关联 DOI/PMID、实际取得的全文版本及页码/表格/段落；元数据匹配不能替代全文核验。无法取得、无法解析、原文未报告分别标记，未知内容不得补齐。数值、单位、组别、时间点、样本量与分母逐项核对。正式报告中的关键结果由可复现计算产生，引用与结论逐项核验；未通过检查的内容保留为草稿。模型自检不能替代独立方法学复核。冻结分析计划，保留数据哈希、代码、依赖、随机种子和运行日志；调整分析须记录理由，不按显著性选择结果。

## 模型路由与 token 预算

| 模块 | 执行方式 | LLM边界 |
|---|---|---|
| 统计分析 | 由传统统计代码/库执行获确认的分析计划，输出可复现表图 | 运行链路零 LLM 调用，不用模型计算统计值或自动决定方法 |
| 检索 | 数据库接口/允许的导出、分页、归档、精确去重由程序处理 | Gemini 仅用于问题澄清、检索式草拟与必要修订；已验证模板优先复用 |
| 文献提取 | 本地解析与结构化校验优先 | 必须调用时只送相关片段，保留原文定位；不得默认把全文反复投入上下文 |
| 写作 | Gemini agent 维护提纲、证据、章节版本、引用与修订任务 | 具备工具调用、状态恢复与校验流程；只依赖审核材料写作，不获得患者原始数据或提交权限 |

具体 Gemini 型号与 API 配置尚未指定，不自动选定或宣称已接入。模型要求适用于工作台目标架构，不代表当前对话底层模型已切换。

对相同文件哈希、策略版本和模型配置复用缓存；阶段只传证据索引及必要片段，不跨 agent 复制全部历史。记录每阶段 token 和调用次数；设可配置预算、重试上限与断点恢复。具体数额待试运行测量后确定，不虚构节省比例。写作质量校验保留，不以节省 token 为由省略证据核验。
